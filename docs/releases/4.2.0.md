# 4.2.0 — Navigation usability

- Added a sidebar page filter over the existing permission-scoped links. Search matches page names, section names, and paths without adding access.
- Added result counts, a no-results message, clear-search control, and Escape-to-clear behavior. Search resets on route changes and is ignored while the desktop sidebar is collapsed.
- Added active-page semantics for nested routes, visible keyboard focus, and 44px navigation targets.
- Made sidebar preference loading safe when browser storage is unavailable.
- Read the sidebar release label directly from package.json to prevent version drift.

Verification: navigation filtering has three regression tests alongside the eight existing permission and offline-queue tests. Authenticated desktop/mobile visual checks remain a manual release check.
