# 4.2.1 — Audit follow-up

- Dashboard queries now check errors, hide incomplete results, and offer retry. The overview explicitly states all-program/all-venue scope and a loaded timestamp; the latest active program badge is contextual, not a filter.
- Login restores validated internal destinations (including query parameters), retains errors inline, and offers administrator-assisted account recovery guidance. Self-service recovery email delivery is not configured by this release.
- Workspace initialization offers a reload action after a delayed connection without clearing saved submissions or bypassing authentication.
- Training fields have associated labels and persistent mutation feedback. Login labels and placeholders are more readable; primary button fills use a darker orange.
- Daily shortcuts use the same My Operations name as the sidebar. Outbox submissions show readable fields before technical JSON.
- Added redirect safety regression tests. Existing authorization and offline isolation tests remain unchanged.

Still requires signed-in device/workflow validation from docs/audit-release-checks.md. This release does not claim to complete those end-to-end scenarios or verify production deployment.
