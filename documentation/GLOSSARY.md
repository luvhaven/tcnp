# Glossary of Terms

To ensure seamless coordination between technology and protocol operations, this glossary defines the domain-specific terminology used throughout the system.

## 👥 Roles & People

*   **Alpha Oscar (AO):** Protocol officer stationed at the "Eagle Square" (Airport).
*   **Delta Oscar (DO):** The primary duty officer assigned to a specific "Papa" for duration of their visit.
*   **November Oscar (NO):** Hospitality officer managing the "Nest" (Hotel) and the "Theatre" (Venue) entertainment.
*   **Papa:** A code name for a High-Profile Guest or Principal minister.
*   **Tango Oscar (TO):** Transport officer managing the fleet and drivers.
*   **Victor Oscar (VO):** Venue officer stationed at the "Theatre."
*   **Echo Oscar (EO):** Officer responsible for managing equipments at the theatre during operations.

---

## 📍 Locations

*   **Eagle Square:** A code name for the Airport (Arrival and Departure point).
*   **Nest:** A code name for the Guest's Hotel or place of residence.
*   **Theatre:** A code name for the primary venue or event location.
*   **Command Center:** The physical or virtual hub where all operations are monitored globally.

---

## 🚗 Transport & Logistics

*   **Cheetah:** A code name for a Vehicle in the protocol fleet.
*   **Telematics:** The real-time data stream (GPS, Speed) coming from a Cheetah.
*   **First Course:** The movement from the Nest towards the Theatre.
*   **Chapman:** Arrival at the venue gate.
*   **Dessert:** The movement returning from the Theatre to the Nest.
*   **Cocktail:** General indicator of a principal in transit.

---

## 🚨 Incidents & Alerts

*   **Broken Arrow:** The signal for an emergency, distress, or serious operational failure needing immediate intervention.
*   **Red Cocktail:** Heavy traffic conditions causing significant delays.
*   **Blue Cocktail:** Mild traffic advisory.
*   **Re-order:** A change in the standard route or operational plan.

---

## 💻 Technical Terms

*   **Call-Sign:** A standardized action that triggers a state change in the database.
*   **Journey:** The core record trackings a specific trip for a Papa from start to finish.
*   **RLS (Row Level Security):** The security architecture that restricts data access based on user role.
*   **PWA (Progressive Web App):** The technology that allows this web application to be installed and run like a native mobile app.

---
> [!NOTE]
> When communicating over radio or in system notes, always use these terms to maintain operational security and clarity.
